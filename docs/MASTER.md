============================================================

Este projeto pode ser uma PRÉVIA COMERCIAL criada para uma prospect adulta que trabalha profissionalmente com acompanhamento/entretenimento adulto.

O site deve tratar a pessoa como uma MARCA PESSOAL.

============================================================
6. HERO CINEMATOGRÁFICO
============================================================

O HERO deve ser uma das partes mais impactantes do projeto.

Sempre que houver uma fotografia adequada:

Utilize a imagem como elemento dominante.

Possibilidades:

- imagem em tela inteira;
- imagem ocupando toda a viewport;
- texto sobreposto;
- tipografia gigante;
- movimento de câmera simulado;
- zoom progressivo;
- parallax;
- deslocamento da imagem;
- máscara;
- camadas;
- mudança de escala;
- revelação progressiva;
- elementos flutuando em velocidades diferentes.

O hero não deve parecer uma imagem estática.

Ele deve RESPONDER AO SCROLL.

Exemplo de comportamento:

Ao entrar:
a imagem ocupa toda a tela.

Ao começar a rolar:
a imagem sofre um zoom lento.

O texto se desloca em velocidade diferente.

Um elemento tipográfico aparece.

A imagem começa a revelar a próxima seção.

A navegação muda de aparência.

A próxima seção invade progressivamente a tela.

Criar uma sensação de câmera cinematográfica.

============================================================
8. SEÇÃO DE TRANSIÇÃO CINEMATOGRÁFICA
============================================================

O site DEVE possuir pelo menos uma transição memorável entre grandes blocos.

Exemplos:

Uma fotografia ocupa a tela.

Durante o scroll:

a fotografia aumenta;

o enquadramento muda;

o texto desaparece;

uma nova imagem aparece por trás;

a nova seção emerge;

a composição muda.

Outro exemplo:

Uma imagem vertical entra pela lateral enquanto outra sai lentamente.

Outro:

Uma fotografia permanece fixa enquanto o conteúdo passa sobre ela.

Criar pelo menos um momento que faça o visitante pensar:

"Caramba, isso é diferente."
